
# Design Tokens

Design tokens are reusable values that maintain a consistent design throughout the application.

| Token | Light Value | Dark Value | Usage |
|---|---|---|---|
| `--bg` | #f8fafc | #0b1220 | Main background |
| `--surface` | #ffffff | #131c2e | Cards and surfaces |
| `--text` | #0f172a | #e2e8f0 | Main text |
| `--muted` | #64748b | #94a3b8 | Secondary text |
| `--primary` | #0ea5e9 | #38bdf8 | Primary buttons and links |
| `--primary-contrast` | #ffffff | #06202e | Text on primary buttons |
| `--border` | #e2e8f0 | #243049 | Borders and dividers |
| `--radius` | 0.75rem | 0.75rem | Card corner radius |
| `--font-sans` | Inter, system-ui, sans-serif | Inter, system-ui, sans-serif | Main font |

## Benefits of Design Tokens

1. They maintain consistent colours and spacing.
2. They make theme changes easier.
3. They reduce repeated hard-coded values.
4. They make the application easier to maintain.
